# Ivonnia Flores Bravo - Psicóloga

Sitio web de presentación profesional para Ivonnia Flores Bravo, psicóloga.

## Descripción

Este proyecto es una página web pensada para dar a conocer el trabajo de Ivonnia como psicóloga: quién es, cómo trabaja, qué servicios ofrece y cómo contactarla. El objetivo es transmitir cercanía y confianza, y facilitar que nuevos pacientes puedan comunicarse para pedir una consulta.

## Objetivos

- Presentar su perfil profesional y su enfoque terapéutico.
- Dar a conocer los servicios y modalidades de atención.
- Ofrecer una vía de contacto simple y directa.
- Tener presencia online con un diseño sobrio, cálido y fácil de navegar desde cualquier dispositivo.
